# Body Surface Area (BSA) Calculator

## Overview
A beautifully designed, feature-rich Android application built with modern **Jetpack Compose** that accurately calculates Body Surface Area (BSA). Medical professionals, students, and health-conscious users can seamlessly estimate BSA utilizing established clinical formulas.

## Features
- **Accurate BSA Calculations**: Calculates body surface area using both the **Mosteller** and **Du Bois** formulas.
- **Multiple Unit Support**: 
  - Height: Centimeters (cm) or Feet/Inches (ft/in).
  - Weight: Kilograms (kg) or Pounds (lb).
- **Formula Comparison**: View comparative results from different formulas simultaneously.
- **Live Preview**: See real-time calculations as you type.
- **Calculation History**: Save your calculations and review them later. You can delete specific items or clear all history entirely.
- **Customizable Experience (Settings)**:
  - **Themes**: Switch between Light, Dark, or System default modes. Supports Material You **Dynamic Color**.
  - **Defaults**: Set your preferred default height unit, weight unit, and BSA formula.
  - **Feedback**: Toggle Haptic Feedback and Sound Effects for a more tactile and interactive experience.

## Tech Stack
- **Language**: Kotlin
- **UI Toolkit**: Jetpack Compose (Material 3)
- **Architecture**: MVVM (Model-View-ViewModel)
- **Navigation**: Jetpack Compose Navigation
- **State Management**: Kotlin StateFlow & Coroutines

## Installation
Clone the repository and open the project in Android Studio:

```bash
git clone https://github.com/abdullah-ateeq/Body-Surface-Area-Calculator.git
```
Sync the project with Gradle files and run the app on an emulator or physical device.
